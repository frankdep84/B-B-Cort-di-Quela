# Cort di Quèla – Bed & Breakfast a Baranzate

Sito statico (HTML/CSS/JS, nessuna build). Apri `index.html` o servi la cartella con `python3 -m http.server`.

- Contenuti: https://beb.it/cortdiquela/it/
- Ispirazione UI/UX: Good Rooms Guest House (struttura a sezioni con ancore, prova sociale subito sotto l'hero, CTA WhatsApp ripetute, galleria con lightbox, mobile first).
- Le foto sono collegate dal CDN originale di beb.it: per indipendenza, scaricarle in `img/` e aggiornare i percorsi.
